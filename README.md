# Shadow King - Hacker Portfolio

Welcome to **Shadow King**, a unique hacker-themed portfolio built with HTML, CSS, and JavaScript.  
This project features an interactive terminal-style interface, glowing sword slice animation, and a minimalist design.

## Features
- Hacker terminal style layout
- Hover-triggered glowing sword
- Click-to-slice animation that reveals portfolio details
- Clean, fast-loading, and responsive design

## Live Demo
👉 [Visit Shadow King](https://shehbaz97.github.io/Shadow.King/)

## How to Use
Clone this repository and open `index.html` in your browser, or view the live demo above.
